# Motion Designer Job Spec - Flow Grid Tutorial Video

## Project Overview
Create a professional 2-3 minute tutorial video showcasing Flow Grid's key features and value proposition for event organizers. The video should be modern, engaging, and demonstrate the platform's ease of use while highlighting the transformation from chaotic spreadsheets to beautiful, professional event schedules.

---

## Company Background

**Flow Grid** is a modern event scheduling platform designed specifically for multi-day events including yoga festivals, dance workshops, wellness retreats, conferences, and creative workshops. Born from Montreal's vibrant dance community, Flow Grid solves the pain points event organizers face when presenting their events professionally online.

### The Problem We Solve
Event organizers were stuck with:
- Complicated spreadsheets that looked unprofessional
- Expensive, bloated software designed for corporate conferences
- Static PDFs impossible to navigate on mobile devices
- Post-it notes for workshops that would disappear throughout the day

### Our Solution
A platform that combines simplicity with professional polish - empowering organizers to create beautiful, mobile-friendly schedules that reflect the care they put into their events.

### Current Status
- Production platform at **tryflowgrid.com**
- **Early Access**: First 5 events free with Pro features
- Proven success with multiple festivals worldwide
- Target audience: Event organizers, festival coordinators, retreat leaders

## Technical Specifications

### Deliverables
1. **Final Video** (MP4, 1920x1080, 60fps)
   - 2-3 minutes duration
   - H.264 codec, high quality
   - Suitable for web, social media, presentations

2. **Alternative Cuts**
   - 60-second version for social media
   - 30-second teaser/trailer version

3. **Source Files**
   - Project files (After Effects, Premiere, etc.)
   - Individual assets used

### Visual Requirements
- **Screen Recordings**: High quality (1920x1080 minimum)
- **Color Palette**: Match Flow Grid branding
  - Primary: Blue (#2563eb), Purple (#7c3aed)
  - Accents: Orange, Pink, Green (as seen in UI)
  - Background: Light gradients (blue-50 to indigo-100)
- **Typography**: Clean, modern sans-serif (similar to Inter or DM Sans)
- **Animation Style**: Smooth, professional, not overly flashy
- **Transitions**: Clean, modern (avoid cheesy effects)

### Audio Requirements
- **Voiceover**: Professional, warm, approachable (not corporate/stuffy)
  - Male or female voice (your recommendation)
  - Clear articulation, moderate pace
  - Emphasize pain points and benefits
- **Music**: Uplifting, modern, inspiring (royalty-free)
  - Subtle background track, not overpowering voiceover
  - Build energy through the video
- **Sound Effects**: Minimal, tasteful (UI clicks, transitions)

### Screen Recording Needs
We will provide:
- Screen recordings of key workflows
- Access to demo festival account
- Sample data (festivals, sessions, teachers)
- Branded assets (logo, colors)

You should capture:
- Clean, smooth recordings
- Cursor movements (natural, not distracting)
- UI interactions clearly visible
- Mobile mockups for responsive views
